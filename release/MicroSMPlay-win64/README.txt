MicroSMPlay
===========

Windows release build.

Run microsmplay.exe to start. Use the song browser to select a chart and
audio file. Songs and charts are not included; add them through the normal
song-folder workflow.

Controls
--------
Space       Pause/resume
F8          Toggle autoplay
D F J K     Play lanes
Left click  Seek on the timeline
Escape      Exit the play screen

The release package contains the compiled application and its runtime
configuration. If Windows reports a missing runtime component, install the
Microsoft Visual C++ 2015-2022 Redistributable (x64).
